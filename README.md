## Projet en cours de développement

Ce projet de jeu est réalisé sur Godot.
C'est un jeu de course multijoueur avec des mécaniques de course à pied réaliste (endurance, fatigue) avec un style de jeu arcade (arbre de compétences, statistiques du joueur).

Ce projet ne peut pas être exécuté en local pour le moment à cause de son instabilité.

### Fonctionnalités:
- Système de création de personnage (à revoir)
- Course en multijoueur (local, pour l'instant)
- Système de course réaliste/arcade
